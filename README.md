# Sitio Astor Wilson — actualización de herramientas interactivas

Versión de trabajo para publicar en GitHub Pages, basada en el ZIP proporcionado por el usuario (`Sitio_Astor_Wilson_final (1).zip`).

## Qué se incorporó

- Nueva sección **Herramientas** entre **La Suite** y **Astor y Wilson**.
- Navegación por logos reales y fichas de texto breves, en tres categorías: **Principales** (10), **Auxiliares** (8) y **Proyectos** (3).
- Interacción con mouse, teclado, flechas y desplazamiento táctil en celulares.
- Estados diferenciados en proyectos: **En desarrollo** para ORBE y MAITE; **Beta** para NEXO.
- Diseño adaptado a celular, sin plugins, dependencias externas, descargas de software ni llamadas a la nube.

## Archivos modificados o agregados

- `index.html`: nueva sección, acceso en la navegación y referencias al CSS/JS nuevos.
- `assets/apps.css`: estilos aislados de la sección interactiva.
- `assets/apps.js`: textos y funcionamiento de la sección. Para editar las descripciones, modificar el catálogo al comienzo de este archivo.
- `assets/img/apps/`: logos originales tomados de la versión actual del launcher.

Los demás recursos originales (acuarelas, estilos originales, JS original, favicon, logo, `CNAME` y `.nojekyll`) se conservaron.

## Cómo revisar y publicar

1. Descomprimí el ZIP y abrí `index.html` en tu navegador para revisar la interacción localmente.
2. Si está aprobado, subí **el contenido de esta carpeta** a la raíz del repositorio de GitHub Pages, reemplazando `index.html` y agregando los nuevos recursos.
3. Mantené `CNAME` y `.nojekyll` en la raíz.
4. Confirmá la publicación desde la URL habitual; si la versión anterior queda en caché, recargá forzando la actualización.

**Importante:** la sección es descriptiva. No expone datos de causas, evidencia, ejecutables ni enlaces de descarga.
